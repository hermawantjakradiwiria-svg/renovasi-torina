Kebijakan Privasi

Renovasi Torina · Berlaku sejak 2 November 2026

Kebijakan ini menjelaskan bagaimana aplikasi Renovasi Torina ("aplikasi") mengakses, memakai, dan menyimpan data. Aplikasi ini adalah alat pribadi milik Hermawan Tjakradiwiria dan hanya dioperasikan untuk akun Google pemiliknya sendiri.

1. Siapa yang memakai aplikasi ini

Aplikasi ini tidak memiliki pengguna publik, tidak menyediakan pendaftaran akun, dan tidak dijalankan sebagai layanan komersial. Satu-satunya pengguna adalah pemilik akun Google yang memberikan izin akses secara eksplisit melalui proses persetujuan Google (OAuth).

2. Data Google yang diakses

LayananDataTujuan
Google SheetsSpreadsheet pencatatan pengeluaran renovasiMembaca, menambah, dan mengoreksi baris transaksi
Google DriveBerkas di folder bukti renovasiMenyimpan foto nota, struk, dan PDF faktur
GmailEmail berisi faktur/tagihanMembaca dan memverifikasi nilai serta status pembayaran
Google CalendarJadwal proyekMenyusun pengingat pekerjaan dan pembayaran

Aplikasi tidak mengakses layanan Google lain di luar daftar di atas.

3. Bagaimana data dipakai

  • Mencatat setiap pengeluaran renovasi beserta tanggal, jumlah, kategori, dan bukti.
  • Menghitung total pengeluaran, rekap per kategori, dan rekap upah tukang.
  • Menyimpan arsip nota agar dapat ditelusuri kembali.

Data tidak dipakai untuk iklan, profiling, penilaian kredit, atau tujuan apa pun di luar pencatatan renovasi.

4. Penyimpanan dan keamanan

  • Data transaksi disimpan di Google Sheets milik pemilik, dengan akses terbatas pada pemilik.
  • Bukti nota disimpan di Google Drive milik pemilik.
  • Token akses disimpan secara lokal di perangkat pemilik dan tidak pernah dikirim ke server pihak ketiga.
  • Akses dapat dicabut kapan saja melalui Setelan keamanan akun Google.

5. Berbagi data dengan pihak ketiga

Aplikasi tidak menjual, menyewakan, maupun membagikan data Google kepada pihak ketiga. Tidak ada SDK iklan, tidak ada alat analitik pihak ketiga, dan tidak ada transfer data ke server di luar Google.

Kepatuhan Google API Services User Data Policy

Penggunaan dan pemrosesan informasi yang diterima dari Google API oleh aplikasi ini mematuhi Google API Services User Data Policy, termasuk persyaratan Limited Use. Data hanya dipakai untuk menyediakan fungsi yang terlihat oleh pengguna dan tidak dialihkan ke pihak lain.

6. Retensi dan penghapusan

  • Data disimpan selama proyek renovasi berjalan dan selama diperlukan untuk pembukuan.
  • Pemilik dapat menghapus baris data, berkas, atau seluruh spreadsheet kapan saja.
  • Permintaan penghapusan data dapat dikirim ke alamat email di bawah dan akan diproses dalam 7 hari kerja.

7. Hak pengguna

  • Melihat data yang tersimpan (ada di spreadsheet dan Drive milik sendiri).
  • Memperbaiki atau menghapus data.
  • Mencabut izin akses aplikasi kapan saja.

8. Anak-anak

Aplikasi ini bukan untuk anak-anak dan tidak dengan sengaja mengumpulkan data dari anak di bawah 13 tahun.

9. Perubahan kebijakan

Kebijakan ini dapat diperbarui bila cakupan fungsi aplikasi berubah. Versi terbaru selalu tersedia di halaman ini beserta tanggal berlakunya.
